# 📚 book-slimmer

**把一本书读薄，不丢关键信息。**

> 一个开箱即用的 AI 拆书 Skill：输入 **PDF / EPUB 文件**或**书名**，输出一份结构化薄书（约原书 10% 篇幅）——论点、论据、逻辑链全部保留，**每个要点都可回溯出处**。

## ✨ 特性

| 能力 | 说明 |
|---|---|
| 📥 **两种输入模式** | 上传 PDF/EPUB 本地解析（出处精确到**页码/段落锚点**）；仅书名联网检索（章节级出处，多源交叉核验） |
| 🧬 **七基因书型适配** | 人物 / 叙事 / 论证 / 模型 / 历史数据 / 美学 / 经验——**动态判定**每本书的基因组合，提取策略跟随基因，不预设书型 |
| 🎚 **三阅读模式** | 速读 15′（精华）/ 精读 1h（分层提取）/ 深度（七基因 + 批判 + 金句）——想看书没时间的人按需取用 |
| 🏷 **信心分级 A-D** | A=原文精读（锚点）/ B=原文略读 / C=网络多源核验 / D=网络单源——出处可信度一目了然，绝不虚标 |
| 🖥 **HTML 交互分屏输出** | Tab 分屏、点击展开、原生 JS 单文件自包含，无需任何外部依赖 |
| 🛡 **防失真铁律** | 不伪造引用、批判性评论必写、篇幅自律（10% 左右）、抽样盲区如实标注 |

## 🚀 快速开始

### 安装（任选一种 Agent 生态）

把 [`book-slimmer/`](book-slimmer/) 目录复制到你正在使用的 AI Agent 的 skills 目录：

```
WorkBuddy     →  ~/.workbuddy/skills/
Claude Code   →  .claude/skills/
Codex         →  参照 AGENTS.md 约定
```

### 使用

在你的 Agent 对话中说：

```
拆《书名》                    # 模式 B：联网检索（目录 + 多源读书笔记交叉核验）
拆《书名》 + 上传 .epub/.pdf  # 模式 A：本地解析（锚点/页码级出处）
```

（模式 B 无原书文本时，输出为结构化提炼而非逐字引用，出处精度到章节级——拆书说明中会如实标注。）

## 🎯 方法论：五步法读薄

**核心信念**：读薄不是删减，而是把书**还原成骨架**——论点、论据、逻辑结构，只留这三样。丢掉的永远是"肉"（修辞、重复、铺陈），保住的永远是"骨"（主张、证据、结构）。

```
① 全局透视    先读目录/序跋，画全书地图，回答：解决什么问题、几条论证线、各章位置
② 分层提取    每章抓三层：论点（主张什么）/ 论据（凭什么）/ 结构（怎么串）
③ 降维压缩    叙述改写成结构化语言：定义、命题清单、因果链、对比表
④ 批判校验    反向还原测试：能否凭薄书向没读过的人完整复述？卡壳即补；出处逐条可回溯
⑤ 输出薄书    固定结构文档，篇幅压至原书约 10%
```

**书型基因判定（Step 2.5）**：正文提取前先判定本书七基因强度（主/中/辅/弱），提取重心跟随主基因——原则型书拆"原则清单"、教科书拆"模型库"、叙事型书拆"大判断"、机制型书拆"因果链"。
